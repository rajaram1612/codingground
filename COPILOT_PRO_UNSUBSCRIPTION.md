# How to Unsubscribe from GitHub Copilot Pro

This guide provides step-by-step instructions on how to unsubscribe from GitHub Copilot Pro.

## Prerequisites

- You must be signed in to your GitHub account
- You must have an active GitHub Copilot Pro subscription
- You need access to your GitHub account settings

## Unsubscription Methods

### Method 1: Through GitHub Website

1. **Sign in to GitHub**
   - Go to [github.com](https://github.com)
   - Sign in with your GitHub credentials

2. **Access Your Account Settings**
   - Click on your profile picture in the top-right corner
   - Select "Settings" from the dropdown menu

3. **Navigate to Billing Section**
   - In the left sidebar, click on "Billing and plans"
   - You'll see your current subscriptions and billing information

4. **Locate GitHub Copilot Pro Subscription**
   - Look for "GitHub Copilot Pro" in your active subscriptions
   - Click on "Edit" or "Manage" next to the Copilot Pro subscription

5. **Cancel Subscription**
   - Click on "Cancel subscription" or "Cancel GitHub Copilot Pro"
   - Confirm your cancellation when prompted
   - You may be asked to provide a reason for cancellation

6. **Confirmation**
   - You should receive a confirmation that your subscription has been cancelled
   - Your Copilot Pro access will continue until the end of your current billing period

### Method 2: Through GitHub CLI (Advanced Users)

If you have GitHub CLI installed and configured:

```bash
# Check current subscriptions
gh api user/copilot

# Note: Direct cancellation via CLI may not be available
# You'll likely need to use the web interface for cancellation
```

### Method 3: Through GitHub Mobile App

1. Open the GitHub mobile app
2. Tap on your profile icon
3. Go to "Settings"
4. Tap on "Billing"
5. Find GitHub Copilot Pro and tap "Manage"
6. Follow the cancellation prompts

## Important Notes

### What Happens After Cancellation

- **Immediate Effect**: Your subscription is marked for cancellation
- **Access Period**: You retain Copilot Pro features until your current billing period ends
- **Data**: Your Copilot usage history and settings are preserved
- **Reactivation**: You can resubscribe at any time

### Billing Information

- **Prorated Refunds**: GitHub typically doesn't provide prorated refunds for partial months
- **Next Billing**: No future charges will occur after cancellation
- **Receipt**: You should receive an email confirmation of the cancellation

### Alternatives to Consider

Before cancelling, consider these alternatives:

1. **Downgrade to Copilot Individual**: If you don't need Pro features, consider the individual plan
2. **Pause Subscription**: Some users prefer to pause rather than cancel completely
3. **Student/Teacher Discounts**: Check if you're eligible for educational discounts

## Troubleshooting

### Common Issues

1. **Can't Find Billing Section**
   - Make sure you're signed in to the correct GitHub account
   - Check if you're part of an organization that manages your subscription

2. **Subscription Managed by Organization**
   - If your Copilot Pro is provided by your organization, contact your admin
   - You cannot cancel organization-managed subscriptions individually

3. **Payment Issues**
   - If you have outstanding payments, resolve them before cancellation
   - Contact GitHub Support if you encounter payment-related errors

4. **Technical Difficulties**
   - Clear your browser cache and cookies
   - Try using a different browser or incognito mode
   - Disable browser extensions that might interfere

### Getting Help

## Frequently Asked Questions

### Q: Will I lose access immediately after cancelling?
**A:** No, you'll retain access until the end of your current billing period.

### Q: Can I get a refund for unused time?
**A:** GitHub typically doesn't provide prorated refunds, but contact support for specific situations.

### Q: Can I reactivate my subscription later?
**A:** Yes, you can resubscribe to Copilot Pro at any time through the same billing settings.

### Q: What happens to my Copilot data and settings?
**A:** Your data and settings are preserved and will be available if you resubscribe.

### Q: How do I know if my cancellation was successful?
**A:** You should receive an email confirmation, and the subscription will show as "cancelled" in your billing settings.
